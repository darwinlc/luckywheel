# Lucky Wheel 🎡

A kid-friendly spinning wheel in a single HTML page.

- 4 lists to spin: Friends, Activities, Books, Snacks — kids can edit each one (saved on the device)
- 5 looks: Candy Pop, Jungle Safari, Space Rocket, Ocean Splash, Crayon Doodle
- Sounds, confetti, works on phones

## Add to the iPhone / iPad home screen

1. Open the site in **Safari**.
2. Tap **Share** → **Add to Home Screen**.
3. It appears as **Lucky Wheel** with the wheel icon and opens full screen.
